OFFICIAL NOTAM / SETUP

実データの接続手順

この版はFAA・ICAOのNOTAM専用です。現在はAPI利用承認・認証情報・レスポンス仕様が未取得で、実データには未接続です。デモは別のデータ領域に分離しています。

1. FAAにAPI利用を申請する

FAA公式FAQの「How can I access ... NMS-API distribution interface?」を確認し、記載された窓口 7-AWA-NAIMES@faa.gov に利用申請してください。自己登録だけで即時にキーが出る方式とは確認できていません。

申請には、個人の非営利研究・フライトシミュレーター向けNOTAM可視化、対象国、30分ごとの取得、GitHub Pagesでの表示、公開リポジトリへのJSON保存を予定していることを伝えてください。無料利用の可否、外国発行NOTAMの範囲、再配布条件、認証方式、仕様書とサンプルJSONを確認します。こちらからメールは送信していません。

2. ICAOは試用枠を確認する

ICAO API Data Service → GET STARTEDから登録手続きへ進みます。公式案内の無料枠は試用25回です。継続無料・30分更新を保証するサービスではないため、この版では自動接続を有効にしていません。

FAAまたはICAOから案内された認証情報を受け取った後、秘密情報を除いた仕様書・レスポンス例を共有してください。認証・ページング・取消処理・境界形式を実際の仕様に合わせて確定します。キーだけを登録しても、未確定のAPI仕様は補完されません。

3. キーはGitHub Secretsへ直接登録

  1. リポジトリの Settings → Secrets and variables → Actions を開きます。
  2. New repository secret を押します。
  3. 名称を FAA_API_KEY または ICAO_API_KEY、Secret欄を発行された値として保存します。

キーはチャット、JavaScript、公開JSON、Issuesに貼り付けないでください。ワークフローからPythonに環境変数として渡す準備は済んでいます。クライアントID・シークレットやOAuthが必要な場合は、実際の仕様に合わせた追加設定が必要です。

4. 仕様確認後の接続

config/sources.jsonの対象国に provider: FAA または ICAO と検証済みAPI設定を登録します。schema_verified: trueとsnapshot_confirmed: trueは、仕様と全件取得を確認してから設定します。APIのURLや項目名は推測で埋めません。

取得→候補抽出→形状検査→国別JSON→公開の処理は実装済みです。一般的な全件JSONのフィールドマッピングに対応しています。FAA専用OAuth、AIXM、差分形式、ICAO独自形式は仕様確認後にアダプターを確定する必要があります。

更新と費用

取得予定は毎時07分・37分UTCです。GitHub Actionsの混雑による遅延、API制限、長期無活動による停止があります。公開リポジトリと標準runnerを使い、有料サービスは契約していません。永続無料・無保守・世界全件の網羅を保証するものではありません。

海域上のNOTAMは対象ですが、NAVAREA等の海上航行警報の独自配信はこの版の対象外です。

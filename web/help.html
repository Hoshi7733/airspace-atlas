空域と海域を分けて確認

赤はFAA NOTAM、オレンジはNGAおよび海上保安庁（NAVAREA XI・日本航行警報）の公式な海域警報です。海域データはFAAとは独立して取得します。各ソースの取得時刻・対象件数を表示し、警報の詳細から公式原文を開けます。現行一覧から削除された警報は次回の正常取得で除去します。個別の実施時間は自動判定せず原文を提示します。NGAは現行SMAPS APIのNAVAREA IV・XII、HYDROLANT・HYDROPAC・HYDROARCを取得します。世界各地の警報を含みますが、全21 NAVAREAの完全収録ではありません。公海など国未判定の区域は地理的な地域枠で分類します。開始・終了日時や日々の実施時間は原文で確認してください。

NOTAMは提供元または本文で確定した多角形のみ描画します。Q行の概略円、中心・半径だけの円、参照点は地図に表示せず未描画一覧に残します。海域の明示された中心・半径は円として表示します。沿岸線・円弧・除外範囲など確定できない境界は推測しません。

高度・新着・座標ジャンプ

F/G項、提供値、Q行の順に高度情報を確認し、SFC・AGL・AMSL・FLを区別します。Q行由来の高度は概略値です。高度ラベルは拡大時に表示します。

ベルはJSON更新時点で、選択条件に一致し画面範囲と重なる新しいIDを通知します。初回読込、範囲外、同じIDの本文更新は新着件数に含めません。端末がスリープすると更新は遅れます。

座標ジャンプは十進度で、緯度 −90〜90、経度 −180〜180を入力します。西経と南緯はマイナスです。

抽出条件と試作入口

ミサイル、ロケット、射撃、武器訓練、軍事演習、安全保障上の制限などを根拠付きで抽出します。一般的なDanger・RestrictedやWXXだけでは採用しません。ルール方式のため誤判定や取りこぼしをゼロにはできません。

簡易パスワードは試作画面の入口です。公開リポジトリとJSONは保護しません。機密情報を扱う用途ではサーバー側認証が必要です。

GETTING STARTED

3つの操作で、区域を確認。

01

地域と国を選ぶ

250の国・地域からチェックボックスで複数選べます。上の地域タブを押すと、その地域だけを表示してカメラを移動します。国のチェック状態は保存され、チェックを変更すると「選択した国」モードへ切り替わります。「世界全体」で全配信区域を確認できます。国名クリックでその国へ移動します。国の分類は参照地点の所在地コードとOurAirportsの対応表に基づきます。ICAO接頭辞による推定やFAA国内分類による発行国判定も含み、詳細に分類根拠を表示します。区域全体がその国の領空内にあるという意味ではありません。判定できないものは「国未特定」に残ります。

02

警報を探す

検索欄に区域名、識別子、Qコード、原文の語句を入力します。例：MISSILE、FIRING。表示レイヤーのチェックで種類を切り替えられます。

03

原文と条件を読む

一覧の区域名で詳細が開きます。地図の赤い区域をクリックすると詳細を開き、PDFの選択も切り替わります。開始・終了時刻、高度、運用時間条件、出典と原文を確認します。

画面は30分ごとに自動同期します。

地図右上に公開JSONの最終同期時刻、次回までのカウントダウン、最終試行と成否を表示します。同期成功はブラウザが公開ファイルを読めたことを示し、航空APIの取得成功とは別です。画面下にはAPI側の取得日時を表示します。一部または全体の通信失敗時は最後の完全同期時刻を更新せず、前回データを保持します。

端末のスリープやバックグラウンドではブラウザがタイマーを遅延させる場合があります。画面に戻った際、期限を過ぎていれば1回だけ同期します。接続が戻っても期限前には自動リクエストを増やしません。

MAP LEGEND

赤い枠の意味。

Restricted＝制限、Danger＝危険、Prohibited＝禁止の候補です。キーワードによる抽出を含み、現在の有効化や法的な飛行禁止を自動確定するものではありません。

実線：提供された形状

空域は提供元または本文の多角形、海域は本文の多角形または明示された円です。

未描画：境界を確定できない空域

概略円を正確な境界に置き換えることはできません。未描画一覧から原文を確認できます。

READ THE STATUS

更新状態も、情報の一部です。

30分ごとの取得予定

GitHub Actionsが毎時07分・37分（UTC／日本時間も毎時07分・37分）に取得を試みます。国際・国内・FDC・軍用・国内軍用の5分類を初回と原則24時間ごとに取得し、その間はlastUpdatedDateによる変更分を取り込みます。分類間の通信は3分以上空けます。初回の取得には約15分かかります。前回の試行から30分未満の再実行では前回ファイルを使います。遅延や失敗があるため即時リアルタイムではありません。

「今すぐ再読込」：公開JSONのみ

公開済みJSONだけを読み直し、その時点から次の30分を数え直します。同期中はボタンを無効にして重複通信を防ぎます。航空APIやGitHub Actionsを起動しません。

未描画・未取得

座標がない、形状が未対応の警報は「未描画」に残ります。接続失敗時は前回データを保持し、60分を超えると古いデータとして表示します。

LOCAL PDF REPORT

選択した警報を、A4レポートに。

  1. 地図の区域をクリック、または一覧の「PDFに選択」をチェックします。選択区域はオレンジの枠になります。
  2. 複数の区域を選び、「PDFレポートを作成」を押します。
  3. ID、参照地点の国・地域名、機関・出典、取得日時、有効期間、原文、取得できた全座標を収録したPDFがダウンロードされます。

PDF生成はブラウザ内だけで行い、選択した警報をサーバーに送信しません。日本語を安定して印刷するためページを画像としてPDF化しています。PDF内の文字検索・コピーには対応しません。印刷はダウンロードしたPDFから行ってください。

検索・国・レイヤーの切替で隠れた警報も、選択中ならレポートに含みます。「警報の選択を解除」で一括解除できます。失効・削除された警報は更新時に選択から外れます。デモには架空データの表示が付きます。1回150ページを超える場合は件数を減らしてください。

参照点は危険区域の境界ではありません。

ポリゴンは提供された境界、Q行の円は概略範囲です。点しか取得できない警報は小さな参照点として描き、半径を推測しません。単位が仕様書で確認できない半径の数値は円の描画に使用しません。位置がない警報も「未描画」に残り、詳細・原文の確認とPDF選択ができます。

失効・取消された警報は現在の表示対象から除外します。日々の運用時間は原文を確認してください。

SCOPE & LIMITS

このマップで分かる範囲。

対象はFAA NMS本番環境の5分類で取得できたNOTAMのうち、制限・禁止区域や、ミサイル・ロケット・射撃・演習に関連する危険区域の候補です。一般気象のSIGMETは取得しません。

海上に位置するNOTAMは表示対象ですが、海上保安機関が発行する航行警報（NAVAREA等）は別の配信系統です。このNOTAM専用版では、それらの海域警報を網羅しません。

期限切れは表示から除外します。日々の断続的な運用時間は原文を表示する方式です。研究・シミュレーター用であり、実際の航空・船舶の運航判断には使用できません。

本文からの形状と表示時刻

明示された中心・半径、直線境界の座標列も抽出します。円弧・国境沿い・除外区域などの複雑な記述は自動確定せず注意表示を残します。開始前の警報は初期状態では表示しません。「開始前の警報も表示」で切り替えます。日々の断続的な運用時間は原文で確認してください。

中東・表示件数・地図切替

中東タブを追加しました。Q行の概略円は全表示でも描画しません。「取得済み対象を全表示」は開始前も含め表示条件を解除しますが、取得元が配信していない警報や軍事等の抽出条件外は追加されません。NGA受信件数と抽出件数も確認できます。

座標欄には3530N13945E、353000N1394500E、35.5,139.75を入力してEnter。西経はW、南緯はSです。地図は同じOpenStreetMapを標準カラー・淡色モノクロ・ダークの3表示で切り替えられます。
